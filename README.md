## 📖 Sobre o projeto

O **DK_Audio3d** é um resource desenvolvido para o Multi Theft Auto: San Andreas (MTA:SA), criado a partir de uma solicitação de um membro da comunidade **Dekon Drops**, o C4-K6, que buscava um sistema de áudio 3D semelhante aos encontrados em servidores de DayZ.

Utilizando essa ideia como referência, desenvolvi minha própria implementação, permitindo que objetos do jogo emitam sons de forma espacial, proporcionando uma experiência mais imersiva aos jogadores.

Inicialmente, o sistema utiliza uma cadeira como exemplo de objeto sonoro, mas ela pode ser substituída por qualquer outro objeto do MTA:SA. O arquivo de áudio também pode ser trocado pelos arquivos correspondentes do resource.

## ⚙️ Funcionalidades

- 🔊 Reprodução de áudio associado a objetos do jogo.
- 📍 Sistema de som 3D posicional.
- 🪑 Objeto inicial configurado como uma cadeira.
- 🔄 Possibilidade de substituir a cadeira por outros objetos do MTA:SA.
- 🎵 Possibilidade de substituir o arquivo de áudio utilizado pelo sistema.

## 📥 Instalação

1. Baixe o arquivo `DK_Audio3d.zip`.
2. Extraia a pasta do resource.
3. Coloque-a no diretório `resources` do seu servidor MTA:SA.
4. Confira os arquivos e as configurações do resource.
5. Inicie o resource pelo console do servidor.

## 🛠️ Personalização

**Alteração do objeto:** modifique o ID do modelo do objeto conforme a estrutura e as configurações existentes no script.

**Alteração do áudio:** substitua o arquivo de som pelo áudio desejado, mantendo o nome ou atualizando o caminho correspondente no código.

Consulte os arquivos do resource antes de realizar alterações.
